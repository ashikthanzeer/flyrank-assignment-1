# AI Study Assistant

An AI-powered study assistant designed to help students organize
learning materials, generate summaries, and answer questions
using a retrieval-augmented generation pipeline.

## Tech Stack

- Next.js
- TypeScript
- PostgreSQL
- Python
- FastAPI
- AI/LLM API

## Planned Features

- Document upload
- AI-powered question answering
- Summarization
- Study material organization

## Status

Currently in development.
